# Local Image Converter

Live: [noclaudkit.com/image-converter](https://noclaudkit.com/image-converter/) · Part of [NoClaudKit](https://noclaudkit.com/)

Also popular page: [HEIC to JPG](https://noclaudkit.com/image-converter/heic-to-jpg.html)

Client-side image converter (HEIC/HEIF, WebP, AVIF, PNG, JPEG -> JPEG/PNG, plus WebP where the browser supports it). No uploads, no cookies, no ads. Static site on GitHub Pages.
See LGPL-NOTICE.md for the HEIC decoder module.
