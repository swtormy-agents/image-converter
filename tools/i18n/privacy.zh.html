隐私声明

  • 不上传。所有解码和编码都在您的浏览器内完成。图片文件和文件名不会发送到任何服务器。页面的内容安全策略（Content-Security-Policy）将网络连接仅限于本站自身的源（connect-src 'self'），转换器代码不会就您的文件发起任何网络请求。
  • 自托管代码。所有脚本（包括可选的 HEIC 解码器模块）均由本站提供。不使用第三方 CDN、字体或跟踪器。
  • 无 Cookie、无分析、无广告、无账户。我们不收集个人数据。
  • 主题设置。本站在您的浏览器中存储的唯一内容是您的主题选择（浅色或深色），保存在浏览器 localStorage 中，键名为 lic-theme。它不会被发送到任何地方，也不是 Cookie。选择“跟随系统”会将其删除；您也可以在浏览器中清除本站数据来删除它。
  • 托管日志。本站托管在 GitHub Pages 上。GitHub 作为托管方，可能出于安全和运营目的记录访问者 IP 地址等技术数据；请参阅 《GitHub 隐私声明》（英文）。我们不接收也不使用这些日志。
  • HEIC 解码器。如果您的浏览器无法原生打开 HEIC/HEIF 文件，页面会从本站加载 WebAssembly 解码器（libheif）。它与本工具的其他部分一样在本地运行。
  • 元数据与限制。转换后的文件不包含原始 EXIF 元数据（包括 GPS 位置）；EXIF 方向信息会被丢弃，因此部分照片可能会旋转显示。对于包含多张图片的 HEIC/HEIF 文件，仅转换第一张（主）图片。

如有疑问：请在 GitHub 仓库中提交 issue。
